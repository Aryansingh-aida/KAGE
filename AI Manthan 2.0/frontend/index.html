Detection pipeline

  1. CaptureRead CAN frames and V2X broadcasts in real time.
  2. TokeniseEncode the 11-bit CAN ID, 8 data bytes, and inter-arrival time per frame.
  3. WindowGroup the last 16 frames into one sequence for the model.
  4. AutoencodeA Transformer encoder compresses the sequence and a decoder rebuilds it.
  5. Score and actHigh reconstruction error blocks the frame, raises an alert, and triggers fail-safe for critical attacks.
